Could not load dashboard_data.json

To fix this:

1. Run Option 8 (Export JSON for Web Frontend) in ./crash_studio so dashboard_data.json is created next to this file.

2. Start a local server in that folder, because browsers block fetch() on file:// pages:

python3 serve.py              # static server plus live filtering
# or, without filtering:
python3 -m http.server 8000

3. Open http://localhost:8000 in your browser.
